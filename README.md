# SWYNEX Final Data Science Project
## Titanic Survival Prediction

### About the Project
This project is an end-to-end Data Science case study
developed as part of the SWYNEX internship.

The objective is to predict passenger survival during
the Titanic disaster using Machine Learning.

### Project Objectives
- Understand and analyze the Titanic dataset.
- Perform data cleaning and preprocessing.
- Explore data using statistical analysis and visualizations.
- Build a Machine Learning classification model.
- Evaluate model performance.

### Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

### Project Workflow
1. Problem Statement
2. Data Collection
3. Data Preparation
4. Exploratory Data Analysis
5. Model Building
6. Model Evaluation
7. Conclusion

### Machine Learning Algorithm
Logistic Regression

### Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

### Repository Structure
- data/ – Dataset files
- notebooks/ – Complete project notebook
- requirements.txt – Required libraries
- README.md – Project documentation

### Conclusion
This project demonstrates the complete Data Science
workflow, from data preparation and analysis to
machine learning and model evaluation.
